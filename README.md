# Договорной контур

Система учёта договоров ООО «Римейк», г. Уссурийск.

Ведение договоров подряда на монтаж и поверку узлов учёта тепловой энергии:
создание из шаблонов, автоматическая проверка перед отправкой, согласование,
исполнение, платежи, гарантийные обязательства, архив по годам.

## Состояние

Проектирование. Работающего движка пока нет — есть интерактивный макет
(лежит вне репозитория, см. «Данные» ниже).

## Что уже сделано

- Разобрана рабочая папка договоров: 561 файл, 62 договора за 2026 год
- Восстановлена схема нумерации `М <номер>-<месяц>-<год>`, сквозная, 01–60
- Извлечены поля из PDF, из старых `.doc` через Word COM и из сканов распознаванием
- Собран макет из 13 экранов на реальных данных
- Сформулированы правила, которые соблюдаются в компании, но нигде не записаны

## Правила предметной области

Выведены из 62 договоров, отклонений не найдено.

| Тип работ | Аванс | Гарантия |
|---|---|---|
| Бюджетные заказчики | 30 % | 24 месяца |
| Капитальный ремонт | 30 % | 5 лет |
| Обычные коммерческие | 70 % | 36 месяцев |
| Сборка узла | — | 12 месяцев |

Гарантия отсчитывается **с даты ввода в эксплуатацию**, а не с даты договора.
Дата ввода фиксируется в акте и обязана попадать в карточку — без неё срок не вычисляется.

```

docs/       документация и схемы
private/    НЕ В РЕПОЗИТОРИИ — макет и материалы с реальными данными
```

## Данные

**Договоры, контрагенты, суммы и сканы в репозиторий не попадают.**
Это коммерческая тайна, среди документов есть контракт по 44-ФЗ с ФГБУ «ЦЖКУ»
Минобороны России, содержащий пункт о защите государственной тайны.

`.gitignore` закрывает `private/`, `data/`, все офисные форматы и PDF, выгрузки
парсера и файлы макета с реальными данными. Перед первым `push` проверить:

```bash
git status --porcelain
git ls-files | grep -iE '\.(doc|docx|xls|xlsx|pdf)$'
```

Вторая команда должна вернуть пустоту.
